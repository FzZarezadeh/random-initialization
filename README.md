

🎲 Random Array Initializer – C# Console App

A simple C# console application that initializes an array with random integers and prints each value. This project demonstrates basic array handling, random number generation, and console output formatting.

---

📦 Features

- User Input:
  - Prompts the user to enter the desired array length.
  - Parses input and creates an integer array of that size.

- Random Initialization:
  - Fills the array with random integers using System.Random.
  - Each element is assigned a unique random value.

- Console Output:
  - Prints each array element with its index.
  - Displays a red "end" message to indicate completion.

---

🛠 Technologies Used

- Language: C#
- Platform: .NET Console Application
- IDE: Visual Studio or any C#-compatible editor

---

🚀 How to Run

1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.
4. Enter the desired array length when prompted.
5. View the randomly generated values in the console.
